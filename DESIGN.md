# How to Adult native design

## Direction
Read mode. A public-library reference desk: topic spines help scanning, the guide title leads, instructions read as a clear page, bookmarks and checked steps retain a place. Native navigation carries the experience. The prototype's random prime-number grid is replaced because it neither contains useful material nor supports a task.

The first viewport asks a useful everyday question through real guides. Search is immediately available, one introductory clothing guide demonstrates the format, and the article index is browsable without onboarding. iPhone uses Guides, Saved and Reminders tabs. iPad and Mac use a three-column library/detail arrangement. Narrow iPad windows return to tabs.

## Written decisions
Marine blue anchors actions and the app icon. Topic symbols use consistent SF Symbols and restrained category colors. System white and dark backgrounds keep reading contrast stable; no cream surface. New York serif appears only in large article/intro titles; system typography carries controls, metadata and instructional prose. Dynamic Type reflows all text without ellipses.

Article steps are checkable across their entire row. Completion uses both a check shape and an accessible value. The checked state does not hide the instructions. Updated instructions have new fingerprints, so stale completion cannot silently carry forward. Tools precede instructions; important cautions and primary-source links follow them. Jurisdiction appears near the article title and in the index.

Saved progress is local and atomic. Save failures preserve the earlier state; invalid saved data remains untouched and can be retried. Downloads are validated before replacing the offline library. Permission requests happen only when saving a reminder. Reminders have explicit Save/Cancel and sound choice.

## Visual vocabulary
- Interactive accent: light #123C72, dark #A6C7FF.
- Featured guide: #123C72 ground with white type.
- App icon detail: #E55437 bookmark.
- Surfaces and secondary text: platform semantic colors.
- Type: largeTitle bold serif; title2 bold section headings; headline step/row titles; body instructions; subheadline summaries; caption metadata.
- Insets: 20–24 pt; reading width at most 760 pt; vertical section gap 28–30 pt.
- Corners: 16 pt featured guide, 12 pt caution/selection backgrounds.
- Motion: native navigation/sheets only; no decorative animation.

## Concept record
Grounded systems considered: field manual, care-label decoding, community noticeboard, transport wayfinding, public-library reference index, cooking mise en place, service worksheet. The direction seed assigned the reference index. Challenger lessons retained as discipline rather than decoration: jackfield/cutting-bench explicit resumable states; origami discrete steps; quarry meaningful section separation; airport immediate choices with time estimates; park poster one clear subject. Literal machinery, film rails, cloud rendering, airport signs and landscape posters do not help an everyday reading task. The existing user preference for direct native implementation informs this session. Optional answer-first/discovery and jurisdiction questions remain open, and the layout assumptions are documented in PRODUCT.md.

## Verification boundary
Native screenshots and a separate review must confirm phone, tablet and Mac behavior, dark appearance and large text before release claims. Browser mockups are not screenshot evidence. Ten marketing images per platform use only genuine native captures, centered concise headlines, an upright hero and outward-fanning supporting screens.
